使用說明

① 建立清單與卡片
左側可新增多個清單（例如不同課次、不同單元）。每張卡只有兩個欄位：正面、反面。可標星、標記已熟練、上移下移調整順序（順序即列印順序）。
正面／反面都支援內嵌圖片：編輯卡片時按「🖼 插入圖片」選本機圖片，或直接把圖片貼上到文字框；圖會自動縮圖並隨卡一起顯示、列印與匯出 HTML。

② Excel 匯入／匯出
每個清單都可獨立匯出 .xlsx（欄位：正面、反面）或 CSV；匯入可選「附加／取代／建立新清單」，也能直接從 Excel 複製兩欄貼上。全程離線，不需外掛程式。
圖片不會進 Excel／CSV（這兩者是純文字）；要保留含圖片的卡片，請用「📤 匯出 → JSON」備份，還原時圖片會一併回來。

③ 四種檢視佈局與排序
網格、列表、表格、聚焦。可搜尋、排序（原順序／正面 A→Z／最近新增／未熟練優先）、篩選（未熟練／已加星／有底面／缺底面／錯題）。手機上這些選項都收在工具列的「▦ 檢視」按鈕裏，桌面版則直接排在同一個工具列。在「原順序」且無搜尋／篩選時，可用卡片左上角的 ⠿ 把手拖動排序；亦可按「⇅ 整理順序」勾選多張批量上移／下移、全選或單張上下移。勾「遮蔽反面」可自測，點一下才揭示答案。

④ 播放與朗讀
點單張卡即播放該卡；按「▶ 播放清單」逐張朗讀，可調語速、間隔、循環、隨機；單張播放後可「續播整份」。
「顯示」有兩種模式：
· 分面：先顯示正面，讀完後自動（或點一下／按 →）才顯示反面。
· 正反同時顯示：正面與反面同時列在同一張卡上，不用翻面；先讀第一面、稍停再讀第二面，然後直接下一張，適合純聽讀。
換卡與換面都是直接換字，沒有翻轉／縮放動畫，不會閃，長時間看較舒服。「順序」可選正→反或反→正（反→正時先讀反面）。
底面一定會先顯示才前進（分面模式）：只要該卡有底面，都會先顯示／朗讀底面才去下一張，不會跳過。「自動連續」開啟＝全自動連續播放；關閉＝每讀完一面停一停，點一下（或按 →）繼續。
鍵盤：← 上一張、→ 下一張、↑ ↓ 或 F 翻面（同時顯示模式下無效）、空白鍵（自動＝暫停／繼續，手動＝繼續下一面）、Esc 結束。手機：左右滑動切換、點一下下一張。
所有播放設定會自動記住（顯示模式、順序、語速、間隔、循環、隨機、朗讀開關），下次進入沿用上一次的設定。每份清單另外各自記住「普通話／粵語」。
電腦與手機都可朗讀：使用瀏覽器內建的 Web Speech（Chrome、Edge、Safari、Android 版 Chrome 均支援）。中英混合的卡面會自動分段，中文用所選語音、英文用英語語音。面板上有 🔊 測試朗讀 按鈕可即時確認這部機能否發聲；狀態列會顯示目前使用的語音。若顯示「未安裝語音」，請到系統的「文字轉語音／朗讀內容」下載中文語音（Windows：時間與語言 → 語音；Android：語言與輸入 → 文字轉語音；iPhone：輔助使用 → 朗讀內容 → 聲音）。若系統完全沒有語音引擎，工具會自動改用無聲計時，翻卡流程照常運作。
離開播放即停止朗讀：按「✕ 結束」、Esc、點播放面板外，或切換分頁／手機切換 App／關閉視窗，都會立即停止發聲並暫停播放，回來後按「▶ 繼續」才會再讀。

⑤ PDF：單面／雙面
匯出 PDF 可選兩種版式（對話框頂部「輸出方式」）：
· 單面（每格正面＋背面）：每張小卡上半印正面、下半印背面（細虛線分隔），單面列印即可對照背誦，適合自製學習卡／溫習紙。
· 雙面（正／背分兩面）：PDF 頁次為「第1張正面、第1張背面、第2張正面…」，背面卡的位置依翻面方式鏡射對調；印表機選「雙面・長邊裝訂」後，正反內容落在同一張小卡的兩面，沿裁切線剪開即成可翻面的背誦記憶卡。
雙面首次使用強烈建議勾「加入校準頁」：先印一張，看「正面1」背後是否為「背面1」，若不對就換一個翻面方式或用 mm 微調。
內容不會被裁掉：文字與圖片一律限制在卡框內並預留安全留白，字級會自動縮到完全容納（單面模式的正／背高度亦按內容多寡分配），頁邊距最少 5mm。列印請選「100% 實際大小」、關閉瀏覽器頁首頁尾。

列印設定：縮放 100%／實際大小，不要勾「配合頁面大小」，關閉頁首頁尾與自動置中，紙張尺寸與此處選擇一致。

⑥ 直接分享
按「↗ 分享」選 PDF 或 Excel 後，會用目前設定即時產生檔案並叫起系統分享選單（手機／平板可直接傳到通訊軟體、電郵或雲端）；PDF 對話框內的「↗ 直接分享」則用對話框裏的設定。桌面瀏覽器若不支援檔案分享，會依序降級為：複製檔案到剪貼簿 → 開新分頁預覽 → 下載檔案，並以提示說明。

⑦ 清單管理
左側可有多份清單，並支援：🔍 搜尋清單（側欄頂部輸入名稱過濾）；📌 置頂（點清單上的 📌 或「⋯」選單，置頂的清單恆排最前）；⠿ 拖動排序（按住清單左側的 ⠿ 把手上下拖移調整順序）；📦 歸檔（收進「已歸檔」區，預設收起，點一下「📦 已歸檔」才展開選取；歸檔清單不會干擾日常，需要時再點開）。每份清單也可複製、重新命名、刪除。

⑧ 自測／測驗與成績
按「📝 測驗」可自測：先選「看正面答反面」或「看反面答正面」；作答方式可選「輸入答案」（自動忽略空白與標點比對），或「選擇題」（從同清單其他卡的答案中隨機混入干擾項，選出正確）。可設定出題範圍與題目順序。完成後會列出每題的✓／✗ 與正確答案，可「重測全部」或「只重測錯題」；並能立即「↗ 分享成績」或「↗ 分享錯題」（叫起系統分享，或降級為複製文字／下載 .txt）。每次測驗成績會自動保存，按設定面板的「📊 歷史成績」可回看歷次分數、查看明細、再次分享。

資料保存
資料存於本機瀏覽器。換電腦或清除瀏覽器資料前，請到「⚙ 設定 → 💾 備份」下載 JSON，再到新環境「⚙ 設定 → ↩ 還原」。清單的語音設定一併保存在備份內。

⑨ 複製卡片內容
在網格／列表／表格／聚焦任一檢視，每張卡的正面與反面右上角都有一個 📋 小鈕，點一下即可把該面的純文字（不含圖片標記）複製到剪貼簿，方便貼到聊天、筆記或其他工具。file:// 離線環境會自動改用內建複製方式。

⑩ 錯題標記與手機操作
測驗中答錯（含未作答）的卡片會自動標上 🔴 錯題 記號（數字為答錯次數）；在「檢視」面板選「錯題」可只看需要復習的卡，「⋯ → 清除錯題標記」或設定裡可一併重置。
手機介面（已為單手操作重新編排）：
· 頂欄只有標題與 ☰／?；「新增清單／匯入」移到 ☰ 抽屜最上方，單手即可按到。
· 工具列只剩「搜尋 ＋ 檢視」一行：按「▦ 網格」開啟底部面板，可切換版面、排序、篩選、卡片大小、遮蔽反面、整理順序，不再層層堆疊。
· 底部導覽：📚 清單（切換清單）、▶ 播放、↗ 分享、⚙ 設定，隨時可達。
· 播放頁全螢幕：卡片自動填滿畫面、按鈕加大成兩行（⏮ 暫停 ⏭／翻面 重讀）；最下方「⚙ 播放設定」預設收起，需要時點一下展開。
· 對話框由底部滑出、全寬顯示，輸入框大字（16px）不會被手機自動放大；卡片編輯的「儲存」在上一行、「刪除／上移／下移」在下一行。
· 列表檢視在手機把反面內容接在正面下方（虛線分隔），不再隱藏；表格檢視隱藏次要欄位，只留正面／反面／操作。
· 操作按鈕、選單項目與輸入框都加大到手指好按的尺寸，有對話框開啟時背景不會跟著滑動。

匿名使用統計
以網頁方式（http／https）開啟時，會透過 Google Analytics（G-G7H3M2VW8T）記錄匿名的功能使用次數，例如匯出、分享、播放，用來改善工具。卡片內容、清單名稱及任何個人資料都不會上傳。直接以本機檔案（file://）開啟、沒有網路、瀏覽器啟用「不追蹤」或在下方關閉時，都不會連線。
